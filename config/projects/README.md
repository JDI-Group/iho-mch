# projects

Configuration files for the IHO project, including the following files:

- `moonchain_geneva.json`（Moonchain Testnet）
- `moonchain.json`（Moonchain Mainnet）

## dictionary

- `name`: Project name. If not specified, the WooCommerce product name will be used.
- `description`: Project description, which will be used as the description in the project list.
- `product`: WooCommerce product ID.
- `target`: The target amount for the project.
- `price`: The price of the project(usd).
- `expire`: The effective duration of the mortgage
